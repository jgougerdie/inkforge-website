# Sharpline

Sharp, no-fluff business articles on global marketing, tax strategy, personal growth, and financial management.

This codebase is a from-scratch rebuild of the site, reconstructed from the live deployment and redesigned to
address the findings of a Viktor UX/CRO audit (visual hierarchy, typography, color contrast, cross-page
consistency, and mobile responsiveness).

## Stack

React + TypeScript + Vite + Tailwind CSS + React Router.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
